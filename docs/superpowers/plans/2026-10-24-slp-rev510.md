**Spec:** [`docs/superpowers/specs/2026-10-21-slp-paseo-design.md`](../specs/2026-10-21-slp-paseo-design.md) rev 5.10 (commit `5947f22` plus the §5.2 title-fallback amendment committed with this plan). Evidence: [`docs/research/smoke-2026-10-23-rerun.md`](../../research/smoke-2026-10-23-rerun.md).

**Core mechanism:** the Supervisor resends the whole premise list with each `slp_brief` → the plugin keeps resent premises (by id, else by kind + title), records only new ones, and drops brief premises a newer brief leaves out → digest lists only live pending premises, before spec approval only. Separately: every `agent.session_open` (create / resume / refresh / import) gets the role env back from the provider, because Paseo does not persist env overrides.

**Decisions:**
- Brief = full snapshot, not a delta: the smoke showed the model resends the full list; a delta would rely on the model behaving.
- Matching falls back to kind + title when the id is missing or wrong (spec §5.2 amendment): the Supervisor's own D# labels drifted from plugin ids in the smoke.
- Dropped = `superseded` with `supersededBy: null`; only premises a brief created and still `proposed`. Active premises and Lead premises are never dropped by a brief.
- Session env is computed from `request.provider` (role → vendor), not from the identity, so a retired agent that Paseo reopens still gets its sandbox home.
- Digest stays one text for agent and human (option A, chosen by the human): empty fields omitted, waits on the human first, bulleted lists with caps.

**System impact:**
- `slp_brief` input premises accept an optional `id`; its result lists the version's premise ids and the dropped ones. Brief events carry `premises: [ids]`.
- Fewer premises: a resent premise no longer becomes a new D#/H#; the digest's "Awaiting spec approval" block disappears after spec approval.
- A Codex reviewer survives `agent reload`/refresh (resumes from `~/.slp/codex-home`); Claude roles keep `CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD` after reload.
- Agents answer in the language of the human's latest message (the Supervisor no longer forces Vietnamese); artifacts and inter-role messages stay English.
- The Supervisor walks the human through each spec (example table) before asking for approval.
- Digest lines change shape (lists become bullets); the watch pack's first line gains "For the Supervisor; no action needed from you."
- The reviewer's end-of-turn nudge names `slp_review`; the ship package says whether approval opens a PR.

/** slp_brief premises carry the id the last slp_brief result gave them (spec §5.2 rev 5.10). */
const BriefPremise = Premise.extend({ id: z.string().optional() });
const normTitle = (s: string): string => s.toLowerCase().replace(/\s+/g, " ").trim();

/** A brief lists every premise the record holds: a resent one keeps its id, matched by id, else by kind and title (the Supervisor's labels can drift, smoke rerun F1). */
function matchBriefPremises(known: readonly PremiseState[], input: readonly z.infer<typeof BriefPremise>[]): { kept: string[]; fresh: z.infer<typeof Premise>[] } {
  const live = known.filter((p) => p.status !== "superseded");
  const same = (p: { kind: string; title: string }, q: { kind: string; title: string }) => p.kind === q.kind && normTitle(p.title) === normTitle(q.title);
  const kept: string[] = [];
  const fresh: z.infer<typeof Premise>[] = [];
  for (const q of input) {
    const hit = live.find((p) => p.id === q.id && same(p, q)) ?? live.find((p) => same(p, q));
    if (hit) { if (!kept.includes(hit.id)) kept.push(hit.id); continue; }
    if (fresh.some((f) => same(f, q))) continue; // the same new premise twice in one call
    fresh.push({ kind: q.kind, title: q.title, ...(q.verify_by ? { verify_by: q.verify_by } : {}), ...(q.source ? { source: q.source } : {}) });
  }
  return { kept, fresh };
}

  if (recent.length) lines.push("Recent ops:", ...recent);
