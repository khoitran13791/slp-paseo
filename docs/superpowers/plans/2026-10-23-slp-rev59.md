# SLP rev 5.9 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sửa các lỗi T21 tìm ra (B-1…B-9, timer sau reload), chuyển luồng đầu sang brainstorm-trước không có cổng brief, chặn đọc `~/.slp`/`~/.paseo` cho reviewer Codex và runner verify, rồi chạy lại một lượt smoke để đo popup, sidebar và số lần anh phải quyết.

**Architecture:** Mọi thay đổi nằm trong plugin `plugin/` hiện có (TypeScript, vitest), theo đúng các module đang có: `roles.ts` (setup vai), `permissions.ts` (chính sách quyền), `human.ts` + `context.ts` (ghi tin của anh), `evidence.ts` + `hooks.ts` (báo commit, nhắc báo cáo), `tools/*.ts` (cổng và spawn), `agentConfig.ts` + `sandbox.ts` (sandbox), `watch.ts` (nhắc anh). Thêm phần client nhỏ (`index.client.ts` + `shared/rpc.ts`) chỉ để gọi RPC "wake".

**Tech Stack:** TypeScript 5.9, Node 22, `@getpaseo/plugin` 0.12.0, `@getpaseo/client` 0.12.0, zod 4, vitest 3, Codex CLI 0.163 (`codex sandbox -P`).

**Spec:** [`docs/superpowers/specs/2026-10-21-slp-paseo-design.md`](../specs/2026-10-21-slp-paseo-design.md) rev 5.9 (commit `ad8ed6c`, `06bf374`). Bằng chứng: [`docs/research/smoke-2026-10-23.md`](../../research/smoke-2026-10-23.md).

**Core mechanism:** anh brainstorm với Supervisor → câu khó thì `slp_spawn` Lead tham vấn ngay khi có brief v1 (không cần duyệt) → Lead viết spec có mục `## Decisions added by the Lead` → anh duyệt spec → plan (Supervisor duyệt) → Peer chạy nền trong workspace thuộc project của repo → plugin tự cho shell trong sandbox của vai Claude, báo Lead đúng một lần mỗi commit → anh duyệt ship.

**Decisions:**
- Không có cổng brief: bỏ `approve_brief` khỏi tool và khỏi phép suy trạng thái; brief chỉ là bản ghi. Lý do: smoke T21, quyết định của anh ở [smoke doc](../../research/smoke-2026-10-23.md) mục Decisions.
- Tin phát lại sau `agent reload` bị lọc bằng mốc theo agent (epoch của timeline + timestamp item mới nhất đã ghi) và bằng nội dung khi epoch đổi, hoặc khi agent chưa có mốc mà đã có tin của anh (agent có từ trước bản này). Lọc thừa thì anh phải gõ lại (an toàn); lọc thiếu thì giả được lời duyệt (không an toàn), nên chọn lọc thừa. Paseo 0.12 tạo epoch mới mỗi lần nạp lại lịch sử (`agent-timeline-store.ts` `initialize` → `randomUUID()`), còn timestamp item phát lại thì tuỳ provider có giữ hay không, nên lọc theo nội dung là lớp chính.
- Shell của vai Claude được plugin `allow` sau các luật từ chối, vì sandbox (`allowUnsandboxedCommands: false`, `failIfUnavailable`) là ranh giới; yêu cầu duyệt shell của Codex bị `deny` vì với Codex đó là xin ra khỏi sandbox. Danh sách lệnh dành riêng chỉ là lớp chặn nhầm lẫn, không phải ranh giới: plugin so trên hai bản của lệnh (bỏ hẳn dấu nháy và `\`; và gộp nội dung trong nháy thành một từ), nhận mọi option toàn cục của git, nhưng không phân tích shell đầy đủ (nháy lồng nhau, biến, `eval` lọt qua được, và sandbox vẫn chặn chúng) và không đẩy lệnh "động" (`$(…)`, biến) sang anh, vì như vậy popup quay lại.
- `Read`/`Grep`/`Glob` chỉ tự cho trong repo của project và `~/.slp-worktrees/<project>/`; tool `Read` không đi qua sandbox nên ngoài vùng đó vẫn chờ anh. `Glob` có `pattern` tuyệt đối, bắt đầu bằng `~` hay có `..` cũng chờ anh.
- Chặn đọc cho reviewer Codex bằng permission profile (`"<path>" = "deny"`, đã kiểm với `codex sandbox -P`) đặt làm `default_permissions` trong `CODEX_HOME` riêng. Paseo 0.12 gửi sandbox kiểu cũ ở cả `thread/start` (`sandbox`) lẫn mỗi `turn/start` (`sandboxPolicy`) khi agent có `modeId` hoặc `providerOptions.sandbox_mode` (`codex-app-server-agent.ts` `buildThreadStartRequest`, `applyTurnWorkflowPolicy`); sandbox gửi kèm có thể đè profile. Vì vậy reviewer Codex không mang `modeId` lẫn `sandbox_mode` (plugin cũng gỡ các khoá sandbox/profile mà request mang vào), để `config.toml` quyết; spike ở Task 8 kiểm đúng đường đó, R10 ở Task 11 kiểm lại qua Paseo, cả sau `agent reload` (Paseo có thể đã lưu `modeId` mà Codex báo về).
- Timer: client plugin gọi RPC `slp.wake` khi app mở và mỗi phút; wake chỉ đưa client Paseo cho plugin, không tự chạy tick, nên nhịp 30 s của timer (và khoảng giãn giữa các tin resume) giữ nguyên dù có bao nhiêu client.
- Báo một lần cho mỗi report và kết quả xử lý của nó (commit + kết quả kiểm, `blocked`, bị từ chối): plugin ghi `ops report_notified {reportSeq, result}` sau khi xếp tin, chỉ khi hàng đợi router đã nằm trên đĩa, và không báo lại khoá đã có. Crash giữa lúc xếp tin và lúc ghi khoá, hay `router.json` ghi lỗi, thì báo lại (thà thừa còn hơn mất).

```ts
interface DaemonConfigLike {
  providers?: Record<string, { extends?: string; paseoTools?: { enabled?: boolean } } | undefined>;
  agentProfiles?: ProfileLike[];
}

export function resolveRoleSetup(raw: unknown, opts: { crossVendorReview: boolean }): RoleSetup {
  const cfg = (raw ?? {}) as DaemonConfigLike;
  const vendor = {} as Record<Role, Vendor>;
  for (const role of ROLES) {
    const p = cfg.providers?.[ROLE_PROVIDER[role]];
    const base = p?.extends;
    if (base !== "claude" && base !== "codex") {
      throw new Error(`SLP: provider ${ROLE_PROVIDER[role]} must exist in ~/.paseo/config.json and extend "claude" or "codex" (found ${base ?? "nothing"})`);
    }
    // Paseo pre-approves its own MCP tools: terminals, schedules and set_agent_mode would bypass the sandbox and the permission policy (T21 B-3).
    if (p?.paseoTools?.enabled !== false) throw new Error(`SLP: ${ROLE_PROVIDER[role]} must set paseoTools.enabled to false in ~/.paseo/config.json`);
    vendor[role] = base;
  }
  // …rest unchanged (crossVendorReview check, profiles)…
}

export function missingProfileError(role: Role): string {
  return `SLP: no agent profile for ${ROLE_PROVIDER[role]}. Create one in Paseo (Settings → Agent profiles) with provider ${ROLE_PROVIDER[role]} and a model.`;
}
```

```ts
const RESERVED = [
  /(^|[\s;&|(`/])paseo(\s|$|\))/,
  /\bgit(\s+(-[cC]\s+\S+|--?[\w-]+(=\S+)?))*\s+(push|commit|merge|rebase|worktree|reset\s+--hard)\b/,
  /dangerouslyDisableSandbox/,
];
/**
 * Two readings of a command, so quoting does not hide a reserved word (review Codex 2026-10-23): quotes and backslashes removed
 * ("paseo" ls, pa""seo, p\aseo), and each quoted string squashed into one word (git -C '/repo with spaces' commit). Nested quotes,
 * variables and eval still get through; this guard catches mistakes, and the sandbox is the boundary (spec §4).
 */
const readings = (command: string): string[] => [
  command.replace(/["'\\]/g, ""),
  command.replace(/'([^']*)'|"([^"]*)"/g, (_m, a: string | undefined, b: string | undefined) => (a ?? b ?? "").replace(/\s+/g, "_") || "_"),
];
```

export interface TimelineItemLike { type?: string; text?: string; messageId?: string | null; clientMessageId?: string | null; name?: string }
export interface TimelineEntryLike { item: TimelineItemLike; timestamp?: string }
export interface AgentTimelineMark { epoch: string | null; lastTs: string | null }

export class SeenIds { /* unchanged */ }

export class TimelineMarks {
  private readonly marks: Record<string, AgentTimelineMark>;
  constructor(private readonly file: string, private readonly onError?: (error: unknown) => void) { this.marks = readJson<Record<string, AgentTimelineMark>>(file, {}); }
  get(agentId: string): AgentTimelineMark | undefined { return this.marks[agentId]; }
  set(agentId: string, mark: AgentTimelineMark): void {
    this.marks[agentId] = mark;
    try { writeJson(this.file, this.marks); } catch (error) { this.onError?.(error); }
  }
}

const ENVELOPE = /^<paseo-system[\s>]/;
/** Router deliveries: "[SLP plugin] …", "[SLP from lead · f] …", "[SLP watch #3 · f]", "[SLP] You are the Lead …". */
const PLUGIN_TEXT = /^\[SLP[\s\]]/;

/**
 * New human prompts in a timeline page. `agent reload` replays the history with new message ids (T21 B-4): an item no newer than the newest
 * recorded one is history, and after the timeline epoch changes, a text the human already sent is treated as history too. Dropping a genuine
 * repeat only makes the Supervisor ask again; recording a replay would forge an approval.
 */
export function extractHumanMessages(
  entries: readonly TimelineEntryLike[], epoch: string | null, mark: AgentTimelineMark | undefined,
  isPluginId: (id: string) => boolean, seen: SeenIds, priorTexts: ReadonlySet<string>,
): { messages: Array<{ messageId: string; text: string; timestamp: string | null }>; mark: AgentTimelineMark; replayed: number } {
  // No mark but messages already recorded: the agent predates the marks, so its timeline may be a replay too (fail closed).
  const replay = (mark === undefined && priorTexts.size > 0) || (mark?.epoch != null && epoch != null && epoch !== mark.epoch);
  let lastTs = mark?.lastTs ?? null;
  let replayed = 0;
  const messages: Array<{ messageId: string; text: string; timestamp: string | null }> = [];
  for (const { item: it, timestamp } of entries) {
    if (it.type !== "user_message" || typeof it.text !== "string" || ENVELOPE.test(it.text) || PLUGIN_TEXT.test(it.text)) continue;
    const ids = [it.messageId, it.clientMessageId].filter((x): x is string => typeof x === "string" && x.length > 0);
    if (!ids.length || ids.some(isPluginId)) continue;
    const id = ids[0]!;
    if (seen.has(id)) continue;
    const ts = typeof timestamp === "string" ? timestamp : null;
    const old = ts !== null && mark?.lastTs != null && ts <= mark.lastTs; // ISO 8601 strings compare in time order
    if (old || (replay && priorTexts.has(it.text))) { seen.add(id); replayed += 1; continue; }
    seen.add(id);
    messages.push({ messageId: id, text: it.text, timestamp: ts });
    if (ts && (!lastTs || ts > lastTs)) lastTs = ts;
  }
  return { messages, mark: { epoch: epoch ?? mark?.epoch ?? null, lastTs }, replayed };
}

export function claudeSandbox(ident: Identity, config: SlpConfig, cwd: string, stateDirs: string[]): Record<string, unknown> {
  const impl = ident.role === "peer-impl";
  return {
    enabled: true, failIfUnavailable: true, autoAllowBashIfSandboxed: true, allowUnsandboxedCommands: false,
    filesystem: { denyWrite: [impl ? join(cwd, ".git") : cwd], denyRead: [...new Set([...stateDirs, ...config.sandbox.denyRead.map(expandHome)])] },
    network: { allowedDomains: impl ? config.sandbox.claudeAllowedDomains : [], allowLocalBinding: false },

}

/** A Codex permission profile on top of :workspace that denies reading each path (checked with codex sandbox -P, 2026-10-23). */
export function codexDenyProfile(name: string, denyRead: string[]): string {
  return [`[permissions.${name}]`, `extends = ":workspace"`, "", `[permissions.${name}.filesystem]`, ...denyRead.map((p) => `${JSON.stringify(p)} = "deny"`), ""].join("\n");
}

export function ensureCodexHome(dir: string, sourceHome: string, denyRead: string[]): string {

/** What has waited on the human longer than limits.humanReminderMinutes, keyed so each wait is reminded once. */
export function humanWaits(ctx: Ctx, project: string, feature: string, now: Date): Array<{ key: string; what: string; minutes: number }> {
  const events = ctx.stores.feature(project, feature).all();
  const st = deriveFeature(feature, events);
  // Same exclusion as the watch: a halted or shipped feature waits on nobody (review Codex 2026-10-23).
  if (st.halted || events.some((e) => e.kind === "shipped")) return [];
  const out: Array<{ key: string; what: string; minutes: number }> = [];
  const add = (key: string, what: string, sinceMs: number) => {
    const m = minutes(sinceMs, now);
    if (m >= ctx.config.limits.humanReminderMinutes) out.push({ key: `${project}/${feature}/${key}`, what, minutes: m });
  };
  if (st.spec && !st.spec.approved) add(`spec:${st.spec.sha256}`, `approve spec v${st.spec.version}`, Date.parse(st.spec.ts));
  const pkg = [...events].reverse().find((e) => e.kind === "ship_package");
  if (pkg && !events.some((e) => e.kind === "shipped" && e.seq > pkg.seq)) add(`ship:${String(pkg.data.commit)}`, `approve ship ${String(pkg.data.commit).slice(0, 7)}`, Date.parse(pkg.ts));
  for (const c of st.challenges.values()) if (c.open && c.byRole === "supervisor") add(`c:${c.id}`, `decide ${c.id} on ${c.target}`, Date.parse(c.ts));
  for (const a of watchedAgents(ctx, project, feature)) {
    const perm = ctx.pendingPermissions.get(a.agentId!);
    if (perm) add(`perm:${a.agentId}:${perm.since}`, `permission ${perm.name} for ${label(a)}`, perm.since);
  }
  return out;
}

```bash
PASEO=/Applications/Paseo.app/Contents/Resources/bin/paseo
# Prints True/False; exits non-zero when the daemon cannot be asked or the answer cannot be read, so a failure never reads as "absent".
slp_configured() { local out; out=$($PASEO plugin ls --json) || return 1; printf '%s' "$out" | python3 -I -c 'import json,sys; print(any(p.get("id") == "slp" for p in json.load(sys.stdin)))'; }
# 1. Stop the runtime first, so nothing rewrites ~/.slp while it moves (remove throws when slp is not configured: check first).
HAS=$(slp_configured) || { echo "cannot list Paseo plugins; fix the daemon, then rerun this step"; exit 1; }
if [ "$HAS" = "True" ]; then $PASEO plugin remove slp || { echo "plugin remove failed; nothing was moved; rerun this step"; exit 1; }; fi
# 2. Keep this run's state next to T21's, as evidence; restore ~/.slp/config.json to exactly what it was.
mkdir -p ~/.slp/smoke2/state
for f in identities.json router.json seen.json nudges.json resume.json timeline-marks.json; do if [ -e ~/.slp/$f ]; then mv ~/.slp/$f ~/.slp/smoke2/state/; fi; done
if [ -e ~/.slp/.no-config-before-rerun ]; then rm -f ~/.slp/config.json; elif [ -e ~/.slp/config.json.bak-slp-rerun ]; then cp ~/.slp/config.json.bak-slp-rerun ~/.slp/config.json; fi
# 3. Only then the Paseo config, and the canary.
cp ~/.paseo/config.json.bak-slp-rerun ~/.paseo/config.json && $PASEO reload --json
rm -f ~/.paseo/slp-t21b-canary/canary.txt; if [ -d ~/.paseo/slp-t21b-canary ]; then rmdir ~/.paseo/slp-t21b-canary; fi
```
