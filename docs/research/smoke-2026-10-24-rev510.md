## Findings
| # | Severity | What | Evidence |
|---|---|---|---|
| G1 | Important | The Supervisor asked all 8 brainstorm questions with Claude Code's `AskUserQuestion` tool. In Paseo that is a permission request (`kind: "question"`): the answer returns as the tool's input, not as a user message. So the plugin records no `human_message` for those answers (7 premises are stored `source: "human"` with no message behind them), each question is a pending permission (it counts for the human reminder and shows as a card), and an approval asked that way could never pass the quote gate. This run passed only because the Supervisor asked for both approvals in plain chat. Fix candidates: record the answers from `agent.permission_resolved` of a question as human messages, tell the Supervisor to ask in chat, or both. | `paseo permit ls` during the brainstorm; `project.jsonl` (2 human messages before the spec) |
| G2 | Minor | The Lead wrote probe files in `$TMPDIR` (`/private/tmp/claude-503/fbprobe`) with its sandboxed shell, then read one with the `Read` tool → a popup to the human (7 min wait). Deferring is right: `/private/tmp/claude-503` is shared by every Claude Code session of the user. Note: the Claude roles' sandboxed shell can read that shared directory (its `denyRead` covers `~/.slp`, `~/.paseo` and `sandbox.denyRead`). | `paseo permit ls`; SDK `pendingPermissions[0].input.file_path` |
| G3 | Minor (Paseo app 0.12) | The app's question card went stale (it kept showing the answered question 6 while question 7 was pending, timer frozen, sidebar missing `[Lead]`); View → Reload fixed it. Questions 7–8 were answered through the SDK (`respondToPermission`, `allow` + `updatedInput.answers`). | screenshots; `paseo permit ls` |
| G4 | Observation | The Supervisor recorded the brief once after all 8 answers (v2), not after each settled point (spec §6.1). With the snapshot rule this costs nothing in premises; it only delays the record. | feature events seq 1, 10 |
| G5 | Observation | The Lead's long English report on the spec still lands in the Supervisor tab right after the walkthrough (rerun F2 remainder); the walkthrough itself is readable. | Supervisor timeline |
